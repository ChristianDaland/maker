# Raspberry Pi

Prosjekter som kjører på en Raspberry Pi (Linux-datamaskin): kamera, GPIO, robothjerne, sentral for tjenester. Koden ligger i `pi/` i prosjektmappen. Se [docs/01-raspberry-pi.md](../../docs/01-raspberry-pi.md).

Prosjekter opprettes med `verktoy/nytt-prosjekt.sh raspberry-pi "Navn"` og får mappenavn `ÅÅÅÅ-MM-navn`.
