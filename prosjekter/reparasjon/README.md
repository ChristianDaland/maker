# Reparasjon

Reparasjon av ferdige produkter: spillkonsoller, elektronikk, verktøy og lignende. Her er målet å finne og rette en feil, ikke å bygge noe nytt.

Prosjekter opprettes med `verktoy/nytt-prosjekt.sh reparasjon "Navn"` og får mappenavn `ÅÅÅÅ-MM-navn`. Bilder fra demontering og målinger legges i `hardware/` i prosjektmappen.

Verktøyene vi bruker står i [verktoy.md](verktoy.md).
