# Verktøy for reparasjon

Hvilke verktøy vi bruker når vi reparerer, og til hva. Se også [docs/04-elektronikk-og-sikkerhet.md](../../docs/04-elektronikk-og-sikkerhet.md).

## Demontering

| Verktøy | Brukes til |
|---|---|
| Presisjonsskrutrekker med bits | Phillips (PH00–PH1), Torx og **sikkerhets-Torx** (T8/T9, vanlig på spillkonsoller) |
| Plastspaker (spudger) og plektre | Åpne klips og deksler uten å lage merker |
| Magnetisk skruematte / eggbrett | Holde orden på skruene, sortert etter hvor de satt |
| Mobilkamera | Ta bilder av hvert trinn før noe tas fra hverandre |

## Feilsøking og måling

| Verktøy | Brukes til |
|---|---|
| Multimeter | Spenning, kontinuitet (pipetest), motstand, sjekke sikringer og kortslutning |
| Lupe / USB-mikroskop | Se etter sprukne loddepunkter, brente komponenter, korrosjon |
| Laboratoriestrømforsyning med strømgrense | Gi strøm forsiktig når man leter etter kortslutning |
| Termisk kamera (valgfritt) | Finne komponenter som blir varme |

## Lodding og rengjøring

| Verktøy | Brukes til |
|---|---|
| Loddestasjon med temperaturstyring | Lodde om kontakter og komponenter |
| Loddetinn, flussmiddel, avloddingsflette og -pumpe | Fjerne og legge på tinn |
| Varmluftstasjon (valgfritt) | SMD-komponenter, f.eks. HDMI-kontakter |
| Isopropanol (99 %) og pensel | Rense kretskort og fjerne gammel kjølepasta |
| Kjølepasta / termiske puter | Ved remontering av prosessor og minne |
| Trykkluft / blåsebelg | Støv i vifter og kjøleribber |
| ESD-armbånd og -matte | Beskytte komponenter mot statisk elektrisitet |
