# Kombinerte prosjekter

Prosjekter som bruker flere plattformer sammen, f.eks. ESP32-sensorer som sender til en Pi-sentral, eller en robot med Pi og mikrokontroller. Hver del får sin egen undermappe (`firmware/`, `pi/`).

Prosjekter opprettes med `verktoy/nytt-prosjekt.sh kombinert "Navn"` og får mappenavn `ÅÅÅÅ-MM-navn`.

Verktøyene vi bruker står i [verktoy.md](verktoy.md).
