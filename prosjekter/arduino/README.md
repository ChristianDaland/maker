# Arduino

Prosjekter med klassiske Arduino-kort (Uno, Nano, Mega, Leonardo). Merk at mange av disse bruker 5 V-logikk. Koden ligger i `firmware/`.

Prosjekter opprettes med `verktoy/nytt-prosjekt.sh arduino "Navn"` og får mappenavn `ÅÅÅÅ-MM-navn`.

Verktøyene vi bruker står i [verktoy.md](verktoy.md).
