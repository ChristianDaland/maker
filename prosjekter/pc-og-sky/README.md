# PC og sky

Prosjekter uten egen mikrokontroller som kjører på PC-en eller i skyen: dashboards, dataanalyse, skript, skyoppsett. Felles tjenester som MQTT og Grafana hører derimot hjemme i `infrastruktur/`.

Prosjekter opprettes med `verktoy/nytt-prosjekt.sh pc-og-sky "Navn"` og får mappenavn `ÅÅÅÅ-MM-navn`.
